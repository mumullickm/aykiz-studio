What this is

Every file a coding agent touches passes through the same rough stages: understand the request, work out what needs to change, generate the code, reason about edge cases, pull in context it remembers, then act on the file. This maps those stages as six firing regions instead of a log scrolling past.

This page is a scripted animation, not a live connection to a real session or a literal diagram of how Claude Code works internally. It exists to show the shape of the process, not the terminal it actually runs in.
