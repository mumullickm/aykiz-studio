What this website collects

The website has no accounts and no forms. We collect only the following:

  • Usage analytics. Google Analytics and Cloudflare Web Analytics record pages viewed, approximate location, device and browser. Google Analytics uses cookies to do this.
  • Security logs. Cloudflare and GitHub Pages, which host the site, process IP addresses and request data to deliver and protect it.
  • Messages you send us. If you email or message us on WhatsApp, we keep your message and contact details to reply and to run any work we agree.

How we use it

We use this information to understand which pages are useful, keep the site secure and respond to you. We do not sell personal data and we do not run advertising on this website.

Tools that run on your device

Crisp, Drafy and Verbatim process your files and audio in your browser. Those files are not uploaded to us. Verbatim downloads its speech model from a third-party host the first time you use it.
