# Aykiz Intelligence — studio site

Source for [aykizintelligence.com](https://aykizintelligence.com/), the studio site of [Miraz Mullick](https://aykizintelligence.com/founder/) (Dhaka, Bangladesh). One person; brand, product, and growth under one roof.

## What ships from here

| Product | What it is | Where |
|---|---|---|
| [Hirra](https://aykizintelligence.com/hirra/) | Calm, private cat health app for the Gulf. Free care core, Plus adds AI vet triage. | [App Store](https://apps.apple.com/us/app/hirra-cat-health-tracker/id6782975522) |
| [Cat care guide](https://aykizintelligence.com/hirra/guide/) | 21 free, evidence-based answers to the cat questions owners search most. Non-diagnostic, routes to a vet. | Web |

## Stack

Static HTML/CSS/JS on GitHub Pages, custom domain, no build framework. The cat care guide is generated by [`hirra/guide/build.py`](hirra/guide/build.py) (edit the `ARTICLES` list, re-run, commit). `llms.txt` and `llms-full.txt` are maintained for AI/answer engines.
