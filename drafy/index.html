A free QR code generator that asks for nothing

Drafy is a free, offline-friendly QR code generator. It runs entirely in your browser, so there is no account to make, no server to trust, and nothing to upload. The codes it makes are static, which means the data lives inside the image itself. They do not route through a tracking link and they never expire, so the QR code you save today still works years from now.

Is Drafy free?

Yes. Drafy is completely free, with no account, no ads, and nothing locked behind a paywall.

Do the QR codes expire?

No. Drafy makes static QR codes. The data lives in the image itself, so the code keeps working forever and never depends on a server.

Does my data leave my device?

No. The QR code is built entirely in your browser tab. Nothing you type, and no logo you add, is uploaded anywhere.

What can I make a QR code for?

A link, plain text, Wi-Fi login, email, SMS, phone number, a map location, or a contact card (vCard). Each type is encoded correctly so it scans the way you expect.

Can I download the QR code as an image?

Yes. Save it as a PNG or a vector SVG. You can also set the colours, cell and eye shapes, error correction level, and drop a logo in the centre.
