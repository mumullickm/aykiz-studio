Drafy

Drafy makes static QR codes that last forever: free, offline, no account, no ads, no tracking. Make it once; it works forever. Try it in your browser at aykizintelligence.com/drafy.

Help

  • My code won't scan. Increase contrast (dark code on a light background). Drafy warns you when a colour pair is too low-contrast. If you added a centre logo, keep it small; error-correction is set high automatically.
  • Can I edit a code after sharing it? No. Static QR codes are permanent by design (that's why they never expire). Finalise your link before you print or share.
  • Does it work offline? Always. Drafy never uses the internet.
